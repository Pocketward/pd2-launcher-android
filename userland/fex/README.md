# FEX for the App userland

FEX-2609.1 (commit `9fbdc00bd6401aff3b32d79e78ff98b8a13e4dcf`) with our Android patches, cross-built for aarch64.

## Build

```sh
userland/fex/build.sh            # FEX + FEXServer
userland/fex/build.sh --thunks   # also the thunk libraries
```

It runs in a pinned container (`Containerfile`), applies `patches/*.patch` in order with `git apply --whitespace=error-all`, checks the blocked-syscall table, runs the resolver test (`resolver-test/`), cross-builds with clang/lld and installs into `out/userland`.

`LinuxSyscalls/Android/BlockedHostSyscalls.inl` in patch 0001 is generated by `gen-blocked-host-syscalls.py` from `blocked-host-syscalls.txt` and `blocked-host-syscalls-eperm.txt`; regenerate it instead of editing it.

## Patches

- `0001-android-blocked-host-syscalls.patch`: FEX never issues a host syscall the Android app seccomp policy blocks; it answers `-ENOSYS` or `-EPERM`, or emulates the call, instead.
- `0002-in-root-lookup-without-openat2.patch`: RootFS lookups walk the path in userspace (`OpenInRoot`) instead of `openat2(RESOLVE_IN_ROOT)`.
- `0003-faccessat2-emulation.patch`: guest `faccessat2` is computed from `faccessat` and `fstatat`.
- `0004-rootfs-mkdir-unlink.patch`: mkdir, rmdir and unlink of a path whose parent exists only in the RootFS act in the RootFS.
- `0005-chdir-rootfs-fallback.patch`: chdir into a RootFS-only directory.
- `0006-thunks-32bit-long-return.patch`: 32-bit thunks return `long`/`unsigned long` in the guest's 32-bit size.
- `0007-thunks-32bit-host-heap-drain.patch`: for 32-bit guests, every small host-heap size class is drained below 4 GiB.
- `0008-thunks-host-glx-errors-not-fatal.patch`: an X error of a GLX request on the host-side display fails the call instead of ending the process.
- `0009-rootfs-open-create.patch`: `open(O_CREAT)` of a file whose parent exists only in the RootFS creates it there.
- `0010-guest-tmp-in-rootfs.patch`: the guest's `/tmp` is always the RootFS's tmp.
- `0011-fexserver-abstract-socket-alone.patch`: FEXServer serves on its abstract socket alone when its filesystem socket's path does not fit `sun_path` (a runtime folder below a long data folder).
- `0012-own-pages-segv-maperr.patch`: a SIGSEGV on FEX's own PROT_NONE pages (the InterruptFaultPage that delivers deferred signals, the JIT guard page) is taken as FEX's with `SEGV_MAPERR` as well as `SEGV_ACCERR`, the code kernels with speculative page faults give a write to a populated PROT_NONE page of a multithreaded process.
- `0013-telemetry-exit-without-sync.patch`: the telemetry file (`<program>.telem`) is created when FEX starts and rewritten in place at exit, with no backup rename and no fsync, so an exiting Wine process, which wineserver kills if it still runs half a second after letting go of it, does not wait on storage (directory updates on a dirsync filesystem).
